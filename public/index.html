DWG→DXF 変換

AutoCAD の DWG を、ドラッグするだけで DXF にします。

  • 無料・登録なし
  • 図面はどこにも送りません
  • 何枚でもまとめて
ここに DWG をドラッグ または、クリックしてファイルを選ぶ

変換の準備をしています…（初めての時だけ 10MB ほど読み込みます）

    安心して使えるように

    • 変換は、あなたのパソコンのブラウザの中だけで行います。図面がこのサイトや他の会社に送られることはありません
    • 変換した DXF は、ダウンロードフォルダに保存されます（AutoCAD 2007 形式の DXF）
    • Chrome・Edge・Safari などで使えます。大きな図面は、少し時間がかかります

    うまく変換できない時

    • DWG によっては、変換できなかったり、文字や寸法の一部が崩れたりすることがあります。大事な図面は、変換後に中身を確かめてください
    • うまくいかない時は、無料の ODA File Converter（Windows・Mac）を使うと変換できることが多いです。使い方はこちら

    逆に、DXF を DWG にしたい時

    • Mac なら、無料のアプリ DXF→DWG で、DXF をドラッグするだけで DWG にできます
    変換した DXF は「WebCAD」で開けます →

    製缶の図面に特化した、ブラウザで動く CAD。囲んで 1 回クリックで寸法がまとめて入る。800 円・買い切り。
